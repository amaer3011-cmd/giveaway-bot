# بوت مسابقات تليجرام

بوت لإدارة المسابقات والسحب العشوائي على قنوات تليجرام.

## المميزات
- لوحة تحكم بالأزرار + معالج إنشاء مسابقة خطوة بخطوة مع معاينة
- اشتراك إجباري في قنوات إضافية (بتتأكد وقت الاشتراك ووقت السحب)
- مؤقت تلقائي لقفل الاشتراك (بيرجع يشتغل بعد إعادة التشغيل)
- سحب عشوائي آمن، استبدال فايز، ابلاغ الفايزين، تصدير CSV

## النشر على Railway
1. ارفع الملفات على مستودع GitHub (أو استخدم Railway CLI).
2. في Railway: New Project → Deploy from GitHub repo.
3. من تبويب **Variables** ضيف:
   - `BOT_TOKEN` = توكن البوت من @BotFather
   - `ADMIN_IDS` = ايديك (من @userinfobot)، ولو أكتر من واحد افصل بفاصلة
4. Deploy. تابع الـ Logs لحد ما تشوف `bot ready`.
5. ضيف البوت **ادمن** في القناة (Post Messages + Edit Messages)، وكمان في أي قناة اشتراك إجباري.
6. ابعت `/start` للبوت في الخاص.

> ملاحظة: البيانات مش متخزنة بشكل دائم، فأي Deploy أو Restart للبوت بيمسح المسابقات والمشتركين. متعملش تعديل أو Redeploy وانت في نص مسابقة شغالة.
> لو احتجت حفظ دائم بعدين: اعمل Volume على `/data` وضيف `DB_PATH=/data/giveaway.db`.

> لازم يكون في Instance واحد بس شغال من البوت (متعملش Replicas)، وإلا هيحصل تعارض Conflict.

## التشغيل محلياً
```
pip install -r requirements.txt
export BOT_TOKEN="..."; export ADMIN_IDS="..."
python bot.py
```
